# PeriApicAI (v2.9.1)

> **AI-Assisted Dental Radiograph Quality & Pathology Assessment Prototype**

PeriApicAI is an experimental, web-based intelligent assistant designed to assist dental students, educators, and clinicians in evaluating periapical radiographs. It pairs automated technical quality appraisal with diagnostic lesion segmentation using multi-modal AI consensus.

---

## ⚠️ Clinical & Research Disclaimer

**PeriApicAI is an experimental academic research prototype and is NOT a certified medical device.**

- **Not Clinically Validated:** The software has not undergone regulatory clearance or formal clinical validation for standalone patient diagnosis.
- **No Substitute for Professional Judgment:** Outputs, bounding annotations, and confidence ratings generated by AI models are advisory only and must never replace independent clinical examination, patient history, and professional diagnosis by a licensed dental practitioner.
- **Human Interpretation Required:** All technical quality findings and pathological interpretations must be critically reviewed and validated by a qualified dental professional prior to making clinical or treatment decisions.

---

## Key Features

- **Dual Assessment Engines:**
  - *Technical Quality Audit:* Detects positioning, beam alignment, and exposure/processing errors across standard periapical views.
  - *Pathology Segmentation:* Pinpoints anatomical landmarks and pathological findings with polygon/bounding-box overlays and treatment recommendations.
- **Dual-Model Consensus Pipeline:** Employs concurrent multi-model inference (Google Gemini) with provenance tracking (`model_a`, `model_b`, or synthesized consensus).
- **Pre-Analysis Validity Gating:** Verifies image orientation, diagnostic validity, and tooth alignment before initiating inference.
- **Cross-Platform Responsive UI:** Optimized for desktop, tablet, and mobile devices across both portrait and landscape viewports, with full dark-mode and bilingual (Vietnamese / English) localization.
- **Admin Audit & Clinical Review Portal:** Secure review panel for session inspection, consensus verification, pathology annotations, and exportable audit logs.

---

## Clinical Workflow

1. **Tooth Selection & Technique:** Select target tooth according to FDI / Universal notation and radiograph acquisition technique.
2. **Image Upload & Validation:** Upload the periapical radiograph; automatic validity gating screens quality and anatomical presence.
3. **AI Inference & Consensus:** Multi-model consensus analyzes technical quality or locates pathological lesions.
4. **Remediation & Review:** Examine overlay contours, confidence metrics, and technical/treatment guidance. Clinicians can adjust or concur with findings.
5. **Session Finalization:** Save clinical summaries, view audit lineage, or export the verified assessment report.

---

## Supported Radiographic Findings

- **Technical Quality Domains:**
  - *Receptor Placement:* Missing crown/apical areas, tilted occlusal plane, cone cut, backwards/reversed receptor.
  - *Angulation & Geometry:* Foreshortening, elongation, horizontal overlap.
  - *Exposure & Processing:* Underexposure, overexposure, motion blur, double exposure, artifact interference.
- **Pathological & Restorative Domains:**
  - *Periapical Lesions:* Periapical radiolucency / apical periodontitis.
  - *Periodontal Status:* Horizontal and vertical alveolar bone loss.
  - *Caries & Tooth Structure:* Dentin radiolucency, coronal enamel breakdown.
  - *Restorations:* Existing filling boundaries, defective margins, endodontic obturations.

## Technology Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React, i18next
- **Backend:** Express, Node.js (`tsx`), Google Gen AI SDK (`@google/genai`)
- **Persistence & Cloud:** Firebase Firestore / Admin SDK, resilient fallback local cache
- **Build & Quality:** Vite, esbuild, Node test runner (`node:test`)

## Local Development Setup

Ensure Node.js (v20+ or v22+) is installed.

```bash
# 1. Install dependencies
npm ci

# 2. Start local development server (binds to http://localhost:3000)
npm run dev

# 3. Validate code and types
npm run lint

# 4. Build for production
npm run build
```
